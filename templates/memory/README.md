# Memoria del coach

Plantilla de repo de memoria para un atleta nuevo de `mcp-coach`. Copia esta
carpeta a un repo **nuevo y privado** y rellena los archivos de `config/`.

- `config/coach.md`: cómo debe comportarse el coach con esta persona (tono, reglas, precauciones). Lo leen tanto Claude en la conversación como el cron semanal.
- `config/objetivos.md`: qué quiere conseguir y cuándo.
- `config/disponibilidad.md`: qué días y a qué hora puede entrenar normalmente.
- `config/zonas.md`: zonas de FC o ritmo. Si aún no se conocen, déjalo así: el coach las irá proponiendo.
- `config/metodologia.md`: qué fuente de datos manda y cómo se corrige un registro.
- `plan/semana-actual.md`: el plan de la semana. El coach lo sobrescribe cada semana.
- `log/` y `health/`: se rellenan solos.
